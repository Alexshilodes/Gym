# Форма

Личное приложение тренировок: одна исходная программа на 30 дней, профиль, журнал нагрузки и таймер отдыха.

## Запуск

Запустите `node preview.cjs` в каталоге проекта и откройте http://127.0.0.1:5173. Также можно открыть index.html напрямую, но хранилище браузера для файла и для сервера различается.

## Персонализация

Цель меняет диапазоны повторений. Опыт, сложность, время занятия и самочувствие меняют число подходов. Короткие занятия уменьшают объём, сохраняя упражнения и расписание исходной программы. Дни восстановления остаются днями восстановления. Длительность — приблизительная оценка.

Имя, пол, возраст, рост и вес сохраняются в профиле. Рабочий вес не рассчитывается из пола или массы тела: приложение показывает последний записанный подход соответствующего упражнения и предлагает подобрать нагрузку с запасом повторов. Автоматической прибавки веса после единственного подхода нет.

Все данные сохраняются локально в localStorage этого браузера; сервер их не получает. Очистка данных сайта удаляет профиль и журнал. Исходные ключи gym-profile, gym-progress, gym-tracker, gym-exercises сохранены.

## Проверка

`node --check app.js`

`node verify.cjs`

verify.cjs проверяет запуск и взаимодействия в модели DOM: профиль, адаптацию, восстановление, журнал, завершение дня и таймер. Это не визуальная браузерная проверка.
