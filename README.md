# Форма — личные тренировки

Статический сайт: index.html, styles.css, app.js и assets/. База упражнений включена в app.js — дополнительных загрузок для запуска не требуется.

## Обновление GitHub Pages

Распакуй gym-update.zip и загрузи файлы в корень репозитория с заменой существующих. Архив содержит только файлы сайта. Версии CSS и JS в HTML обновлены, чтобы Safari загрузил новую версию.

## Данные и навигация

При первом открытии анкета пустая. Ввод сохраняется локально; заполненная корректная анкета автоматически сохраняется после небольшой паузы. Незавершённая анкета восстанавливается при обновлении. Профиль можно сохранить кнопкой. Данные привязаны к браузеру и адресу сайта: очистка данных сайта их удаляет, между устройствами синхронизации нет.

План, журнал и профиль — отдельные разделы. Подходы записываются из плана, в журнале хранится история. Запись веса тела открывается отдельной кнопкой, поддерживает запятую и точку в дробном весе.

## Автоматический подбор

Внутренняя база содержит 40 упражнений с фотографиями оборудования. Свободного выбора упражнений нет. Силовая программа сохраняет структуру A/B/C; для снижения веса используются силовые на всё тело, кардио и восстановление.

Подбор учитывает цель, опыт, оборудование, длительность, самочувствие и уровень нагрузки. Основные движения имеют приоритет; при коротком занятии или усталости исключаются дополнительные упражнения. У новичка предпочтение стабильным простым вариантам. Набор массы добавляет объём, сила отдаёт приоритет основным движениям, тонус и общее здоровье используют всё тело с кардио. Варианты стабильны внутри выбранного дня и не меняются случайно при обновлении.

Рабочий вес не рассчитывается по полу, росту или весу тела: приложение показывает последние фактические результаты и предлагает оставить запас повторов. Фото показывают оборудование, а не технику упражнения. Источники фото: assets/equipment/README.md и sources.json.

## Режим тренировки

Кнопка «Начать тренировку» открывает полноэкранный режим. Он показывает одно упражнение, считает подходы и время, запускает таймер отдыха после силового подхода и восстанавливает незаконченную тренировку после закрытия. Оценка «легко / нормально / тяжело» формирует рекомендацию веса для следующего подхода. Рекомендация всегда остаётся подсказкой.

## Установка на iPhone

После публикации открой сайт в Safari, нажми «Поделиться» → «На экран Домой» → «Добавить». Приложение откроется без панели браузера, получит иконку с гантелью и сможет загружать ранее сохранённую версию без интернета. Для первой установки и обновления нужен интернет. Все профильные данные и журнал остаются в Safari на этом устройстве.

## Проверка

Для разработки: npm install, затем npm test. Проверки используют настоящие HTML-формы и события в jsdom: сохранение и повторное открытие, переходы, черновики, вес тела, журнал и 2880 комбинаций настроек подбора. Это проверки DOM и логики, визуальную проверку в Safari они не заменяют.

Локальный просмотр: node preview.cjs, затем http://localhost:5173.
